# Tableau Executive Dashboard

## Supply Chain Fulfillment & Delivery Performance Analytics

This folder contains the Tableau executive dashboard developed using historical Olist Brazilian e-commerce data.

### Dashboard Overview

The dashboard provides an executive-level view of supply chain performance, including:

- **Total Orders:** 99,441
- **On-Time Delivery Rate:** 93.23%
- **Late Orders:** 6,534
- **Total Freight Charges:** R$2.25 million

### Visualizations

1. Monthly Delivery Performance
2. Fulfillment Stage Bottlenecks
3. Bottom 10 States by On-Time Delivery Rate

### Tools
- Tableau Desktop
- PostgreSQL
- SQL

### Data Source
Olist Brazilian E-Commerce Public Dataset (historical).

This is an independent portfolio project using publicly available data. No proprietary employer data is included.
